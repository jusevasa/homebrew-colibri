# homebrew-colibri

Tap de Homebrew para [Colibrí](https://github.com/jusevasa/colibri), la terminal para macOS pensada para correr varios agentes de código en pestañas.

```sh
brew install --cask jusevasa/colibri/colibri
```

Para actualizar: `brew upgrade --cask colibri`. Colibrí enseña entonces el botón «Actualizar» para reiniciarse con la versión nueva sin perder las pestañas.

`Casks/colibri.rb` lo escribe solo el flujo de publicación de [jusevasa/colibri](https://github.com/jusevasa/colibri/blob/main/.github/workflows/release.yml) en cada versión: no lo edites a mano.
